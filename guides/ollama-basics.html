Getting started with Ollama

Your first local language model in 15 minutes.

What is Ollama?

Ollama is an open-source tool that lets you run large language models (LLMs) on your own computer. No cloud accounts, no API keys to third parties, no per-message billing.

Installation

macOS

brew install ollama
ollama serve

Linux

curl -fsSL https://ollama.com/install.sh | sh
ollama serve

Windows

Download the installer from ollama.com. It installs as a system tray app.

Download your first model

ollama pull qwen2.5:7b
Popular models available:
  • qwen2.5:7b — Great all-rounder, fits on most laptops
  • llama3.2:3b — Fast, efficient, good for simple tasks
  • mistral:7b — Strong reasoning, versatile
  • codestral:22b — Code generation specialist
  • phi3:mini — Microsoft's compact model, runs on anything

Chat with your model

ollama run qwen2.5:7b

Once the model loads, you can chat normally. The model runs entirely on your machine.

Use it as an API

Ollama exposes a local OpenAI-compatible API:

curl http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen2.5:7b",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'

This means any tool that supports OpenAI's API can use your local model — including OpenClaw, LangChain, and dozens of other frameworks.
