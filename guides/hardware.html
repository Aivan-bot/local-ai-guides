Hardware guide: What you need to run AI locally

From your laptop to a dedicated server — pick the right setup for your needs and budget.

The short answer

Your current laptop probably works. Modern CPUs can run 7B parameter models at usable speeds. A dedicated GPU makes it dramatically better.

Quick reference table

+-------------------+---------+-------------+------------------+
| Setup             | Model   | Speed       | Cost             |
+-------------------+---------+-------------+------------------+
| Laptop (CPU only) | 7B      | Slow (~5 w/s)| $0 (you own it) |
| MacBook M-series  | 13B     | Fast (~20 w/s)| Included       |
| Desktop + GPU     | 34B     | Very fast   | $500–$1500       |
| Used A100 GPU     | 70B+    | Blazing     | $1500–$3000      |
| Raspberry Pi 5    | 3B      | Very slow   | $80              |
+-------------------+---------+-------------+------------------+
(w/s = words per second, higher = better)

Option 1: Your current laptop (free)

If you have a Mac with M1/M2/M3 or a Linux/Windows machine with 16GB+ RAM, you can start right now.

  • Best model: Qwen 2.5 7B or Llama 3.2 3B
  • RAM needed: 8GB minimum, 16GB recommended
  • Speed: ~3-8 words/second on CPU

Option 2: MacBook with Apple Silicon (best value)

Apple's unified memory architecture is uniquely suited for local AI. An M-series Mac can run large models that would need $3000+ in PC hardware.

  • MacBook M2/M3 (16GB RAM): Run 13B models comfortably
  • MacBook M2/M3 (32GB RAM): Run 34B models
  • Mac Studio (64GB+): Run 70B class models

Option 3: Dedicated GPU (for teams)

If you're running AI for your business and need speed, a GPU is essential.

+-------------------+-------+-------+------------+
| GPU               | VRAM  | Model | Price      |
+-------------------+-------+-------+------------+
| RTX 4060 Ti 16GB  | 16GB  | 13B   | ~$450      |
| RTX 4090 24GB     | 24GB  | 34B   | ~$1,600    |
| Used RTX 3090 24GB| 24GB  | 34B   | ~$700      |
| RTX 6000 Ada 48GB | 48GB  | 70B   | ~$6,800    |
+-------------------+-------+-------+------------+
Prices approximate as of 2026.
💡 Best bang for buck: A used RTX 3090 (24GB) for ~$700 gives you enterprise-class model support at a fraction of the new price.

Option 4: Cloud GPU (when you don't want to buy hardware)

If buying hardware doesn't make sense yet, rent GPU time:

  • RunPod — RTX 4090 from ~$0.40/hour
  • Lambda Labs — A100 instances from ~$1.50/hour
  • Replicate — Pay per inference, no setup

Storage considerations

Models are large files. Plan accordingly:

  • 7B model: ~4-5 GB
  • 13B model: ~8-10 GB
  • 34B model: ~20 GB
  • 70B model: ~40 GB

SSD storage is strongly recommended — RAM loading speed matters for responsiveness.
