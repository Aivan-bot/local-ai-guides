Ollama + OpenClaw

Install local AI and connect it to your daily tools in 30 minutes.

What you'll build

A local AI assistant that runs on your hardware, responds on Telegram, reads your files, manages your calendar, and automates routine tasks. No cloud dependency. No per-request costs.

Prerequisites

  • A Mac, Linux machine, or Windows WSL2
  • At least 8GB RAM (16GB recommended)
  • Internet connection for the initial download

Step 1: Install Ollama

Ollama is the simplest way to run large language models locally. One command, zero configuration.

# macOS or Linux
curl -fsSL https://ollama.com/install.sh | sh

# Windows — download from https://ollama.com/download/windows

# Start the service (if not auto-started)
ollama serve

Verify it works:

ollama --version

Step 2: Pull your first model

We'll use Qwen 2.5 7B — excellent quality, runs on modest hardware, and supports the OpenClaw tool protocol.

ollama pull qwen2.5:7b

This downloads ~4.5GB. On a normal connection it takes 2–5 minutes. Test it:

ollama run qwen2.5:7b "Write a one-paragraph pitch for a local AI consulting service."
💡 Model selection tip:
  • 7B models — runs on laptops with 16GB RAM
  • 14B models — needs 24GB RAM or a GPU
  • 32B+ models — dedicated GPU/server recommended

Step 3: Set up OpenClaw

OpenClaw connects your local model to your real tools. Let's install it:

# Install OpenClaw CLI
npm install -g openclaw

# Initialize your assistant
openclaw init

During setup, you'll configure:

  1. Model provider — point to your local Ollama instance (http://localhost:11434)
  2. Channels — Telegram, Slack, or web interface
  3. Skills — git, weather, session management, etc.
  4. Crons — scheduled tasks and reminders

Step 4: Connect Telegram (optional but recommended)

Telegram is the easiest channel. Create a bot via BotFather:

  1. Open Telegram, search for @BotFather
  2. Send /newbot and follow the prompts
  3. Copy the API token it gives you

Then in OpenClaw:

# In your openclaw config (usually ~/.openclaw/openclaw.json):
# Add under telegram configuration:
{
  "telegram": {
    "enabled": true,
    "token": "YOUR_BOT_TOKEN_HERE",
    "chatId": "YOUR_CHAT_ID"
  }
}

What you have now

Your local AI assistant is running. It can:

  • Chat with you on Telegram (or your chosen channel)
  • Read and write files on your machine
  • Run shell commands (with your approval)
  • Connect to GitHub, calendars, and other tools via skills
  • Schedule tasks with cron jobs
