Setting up OpenClaw as your AI agent

Connect your local model to your real tools — files, messages, calendars, and more.

What is OpenClaw?

OpenClaw is a local AI agent framework. Unlike a chatbot that just talks back, an AI agent can do things — read your files, run commands, manage your calendar, interact with GitHub, and automate workflows. All running locally on your hardware.

Installation

# Install via npm
npm install -g openclaw

# Initialize
openclaw init

Core configuration

OpenClaw's configuration lives in ~/.openclaw/openclaw.json. Here's the minimal setup for local AI:

{
  "agents": {
    "defaults": {
      "model": "ollama/qwen2.5:7b",
      "provider": {
        "type": "ollama",
        "baseUrl": "http://localhost:11434"
      }
    }
  },
  "channels": {
    "telegram": {
      "enabled": true,
      "token": "YOUR_BOT_TOKEN"
    }
  }
}

Available channels

  • Telegram — Best for personal use. Create a bot with @BotFather.
  • Slack — Great for team setups.
  • Discord — For community/workserver bots.
  • Signal — Private messaging support.
  • Web — Built-in web interface.

Skills — Give your agent capabilities

OpenClaw uses "skills" to add functionality. Each skill is a folder with instructions and scripts that teach your agent how to use specific tools:

  • Git/GitHub — Commit code, create PRs, manage issues
  • Weather — Get forecasts for any location
  • TaskFlow — Multi-step automation workflows
  • Session management — Manage your own conversations

Scheduled tasks (Crons)

Set up automated checks that run on schedule:

# Check email every 30 minutes
# Send daily news digest at 9am
# Monitor a GitHub repo for updates
# Remind you of deadlines

Security

Important for business use:
  • All data stays on your machine
  • Commands run with your user's permissions (approve before execution)
  • No data sent to external APIs (your model runs locally)
  • You control which channels and skills are active
